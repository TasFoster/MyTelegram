## ✨ Возможности

Это **учебный UI-прототип**: собран каркас интерфейса мессенджера на Qt Widgets,
бизнес-логика и сетевой бэкенд пока не реализованы (методы вроде `LoadChats()` —
заглушки, сигналы/слоты не подключены). По факту в проекте есть:

- **Главное окно** (`MainWindow`) с меню-баром и статус-баром, в которое встраивается
  экран чатов.
- **Экран чатов** (`Chats`) с двухпанельной компоновкой в духе Telegram:
  - левая колонка-список диалогов (вертикальный layout под кнопки чатов);
  - правая область выбранного диалога;
  - кнопка в верхней панели.
- **Виджет диалога** (`Chat`) — оформленная область переписки: скруглённая панель
  сообщений, нижняя строка ввода и кнопка отправки (стилизованы через `styleSheet`).
- **Кнопка-чат** (`ChatButton`) — переиспользуемый элемент списка диалогов
  с подписью и цветным фоном.

> Функционал отправки сообщений, хранения данных и реального обмена ещё не добавлен —
> сейчас это визуальный макет интерфейса.

## 🛠 Стек

- **Язык:** C++17
- **Фреймворк:** Qt 6 (модули `core`, `gui`, `widgets`)
- **Интерфейс:** Qt Widgets + `.ui`-формы (Qt Designer)
- **Сборка:** qmake (`MyTelegram.pro`)
- **Тулчейн:** MinGW 64-bit (проверено на Qt 6.10)

## 🚀 Сборка и запуск

```powershell
qmake ; mingw32-make
```

Либо откройте `MyTelegram.pro` в **Qt Creator** и нажмите **Ctrl+R**.

## 📂 Структура

```
MyTelegram/
├── MyTelegram.pro      # проектный файл qmake
├── main.cpp            # точка входа, запуск MainWindow
├── mainwindow.*        # главное окно, встраивает экран чатов
├── chats.*             # экран со списком диалогов и областью чата
├── chat.*              # виджет открытого диалога (сообщения + ввод)
└── chatbutton.*        # переиспользуемый элемент списка диалогов
```

(`.cpp` / `.h` / `.ui` для каждого модуля; каталог `build/` не версионируется.)
